## مشخصات فنی تصاویر

- **فرمت**: WebP (توصیه می‌شود) یا JPG
- **اندازه حداقل**: 400×300 پیکسل
- **اندازه توصیه شده**: 800×600 پیکسل
- **نسبت تصویر**: 4:3
- **حجم فایل**: کمتر از 200KB برای بهینگی
